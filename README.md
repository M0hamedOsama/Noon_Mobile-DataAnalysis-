# 📱 Mobile Market Analysis

This project provides a comprehensive data analysis of the mobile phone market based on data scraped from **Noon.com**. It covers the end-to-end data pipeline, from web scraping and data cleaning to storage in **MySQL** and advanced visualization through **Excel**, **Power BI**, and **Tableau**.

---

## 🚀 Project Overview
The objective of this project is to extract actionable insights from mobile device listings, helping users understand pricing trends, feature distributions, and brand market positioning.

### 🛠 Tech Stack
*   **Web Scraping:** Python (BeautifulSoup, Requests)
*   **Data Processing:** Pandas, NumPy
*   **Database:** MySQL (PyMySQL / MySQL Connector)
*   **Visualization:** Excel, Power BI, Tableau

---

## 📈 Key Insights

### 1. Pricing Trends
*   **Total Market Value:** ~1,548,411.8 EGP.
*   **Premium Segment:** The maximum price observed is 112,222 EGP.
*   **Market Evolution:** Newer models (2024) command higher price points, reflecting the latest technological integrations.

### 2. Market Features & Consumer Preferences
*   **Battery & Charging:** Average battery capacity is 4,595 mAh. Type-C charging is the standard, supporting up to 120W fast charging.
*   **Connectivity:** 4G remains the dominant network type (59%), with 5G capturing a significant 40% of the market.
*   **SIM Capability:** 68% of models support Dual SIM, catering to high-usage demand.
*   **Call Quality:** 51% of models support VoLTE for superior voice call quality.

3.  **Database Storage:** Automated insertion of cleaned data into MySQL.
4.  **Analysis:** Visualization of key performance indicators (KPIs) and market trends.
